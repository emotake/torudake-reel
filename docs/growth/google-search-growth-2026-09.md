# Google検索流入の改善計画（2026年9月）

## 目的

「撮るだけリール」というサービス名を知っている人だけでなく、編集で困っている人が使う具体的な検索語から、実演ページまたはガイドへ到達できる状態を作る。

大量の記事を増やすのではなく、実際の機能・実演動画・利用者が選べる設定を説明できるテーマだけを扱う。

## 検索テーマと入口ページ

| 検索テーマ | 主な入口ページ | 検索後に解決すること |
| --- | --- | --- |
| 動画編集が面倒、投稿できない | `/`、`/use-cases/daily-moments` | 撮ったままの動画を投稿できる形まで進める方法 |
| 動画の自動テロップ、日本語字幕 | `/guide/automatic-video-captions`、`/use-cases/talking-video` | 音声認識、誤字修正、不要部分、表示方法 |
| Instagramリールをスマホで編集 | `/guide/instagram-reels-editing` | 動画1本・複数動画・写真から作る手順 |
| YouTubeショートをスマホで編集 | `/guide/youtube-shorts-editing` | 縦型動画、テロップ、AIナレーションの選び方 |
| 無音動画にAIナレーション | `/guide/silent-video-narration` | 元音声がない動画へ説明音声を付ける方法 |
| 商品・店舗紹介のショート動画 | `/use-cases/shop-introduction` | 複数動画または写真を投稿用の1本へまとめる方法 |

## 今回実装した改善

- 3つの用途ページへ「合う人」「自分で決められること」「よくある質問」を追加
- 自動カット、テロップ、元音声、AIナレーションについて、実際に選べる範囲だけを説明
- 用途ページから関連する詳細ガイドへ文脈付き内部リンクを追加
- トップと3用途ページの実演動画を動画サイトマップへ追加
- 動画の安定URL、サムネイル、タイトル、説明、公開日、尺をGoogleへ明示
- 各用途ページの`VideoObject`から対象ページと運営者を参照

## Search Consoleで確認する項目

公開後に次の順で確認する。

1. `https://torudake-reel.pages.dev/sitemap.xml`を再送信
2. 「動画ページ」で検出動画が4本になるか確認
3. URL検査でトップと3用途ページを確認し、未登録ならインデックス登録をリクエスト
4. 7日後、28日後に「検索結果」のクエリをページ別に確認
5. 表示回数10以上のクエリは、クリック率と平均掲載順位を記録

## 改善判断

- 表示回数が増えない: 検索テーマと本文が一致しているか、インデックス状況と内部リンクを確認
- 平均掲載順位が上がりクリックが少ない: タイトルと説明文を検索者の悩みに合わせて調整
- クリックされるが無料プレビューへ進まない: 検索内容とページ上の実演・CTAの一致を見直す
- 1件の変化で判断せず、原則28日単位で比較する

## 行わないこと

- 実装していない機能を検索語のために記載しない
- 似た文章だけを変えたページを大量生成しない
- 検索順位の購入、相互リンク集、隠しテキストを使用しない
- 内容を変えずに更新日だけを新しくしない
