# 機能仕様

最終確認日: 2026-08-24

公開UIと実装済みの挙動を一致させるための機能一覧です。価格と利用枠の正本は [Stripe課金](../billing/stripe.md)、AI音声の詳細は [AIナレーション](ai-narration.md) に分離しています。

## 入力

| 作成方法 | 入力 | 上限 | 主な仕上げ |
| --- | --- | --- | --- |
| 1本の動画 | 動画1本 | 500MB、5分 | 音声認識、AIナレーション、カット、テロップ、表紙 |
| 複数動画 | 動画2〜5本 | 合計500MB、5分。完成動画は最大90秒 | 選択順を保ち、各動画から1〜2区間をつないで1本化 |
| 写真 | 写真2〜10枚 | UIに表示する検証値に従う | 5種類の自動編集スタイルで縦動画化 |

複数動画は素材を選んだ順番と各素材内の時間順を保ちます。完成した1本の書き出しは、素材数にかかわらず料金プランの動画1本分として扱います。

## 投稿先

編集開始時に次から選択できます。

- Instagram Reels
- YouTube Shorts
- 両方

同じ文字起こしと編集結果から、Instagram投稿文、YouTube Shorts用タイトル・説明文を用意します。YouTubeタイトルは100文字以内に整えます。

## 元の音声を活かす編集

- 自動音声認識と言語指定
- 音量正規化と発話区間分割
- テロップを付ける、付けない
- 認識結果と表示テロップの文章修正
- 自動カット、手動カット、カットしない
- 音声に合わせて映像をつなぎ直す、元の映像の流れを保つ
- SRT、VTT、テロップ文章の保存

テロップを使わない発話区間は、利用者が任意でカット対象にできます。

## AIナレーション編集

- 台本の確認と修正
- 表示テロップと読み方を分離した修正
- 公開中の3種類の声
- テロップを付ける、付けない
- 映像を自動カットする、元の尺と流れを保つ
- 元動画の音量を割合で調整
- ナレーション単体と動画を合わせた仕上がりプレビュー

声と生成処理の詳細は [AIナレーション](ai-narration.md) を参照してください。

## テロップ

| 雰囲気 | 表現 |
| --- | --- |
| ナチュラル | 枠付き |
| インパクト | 枠付き |
| クリア | 文字のみ |
| ポップ | 文字のみ |
| Vlogシンプル | 文字のみ |
| シネマ | 文字のみ |

文章、使用する区間、雰囲気、色を調整できます。選択結果はプレビューと動画書き出しへ同じ条件で反映します。

## 表紙

- アップロードした動画の実フレームを候補に使用
- 9:16の縦長比率
- タイトルとアクセントカラーを調整
- 表紙画像を端末へ保存

動画と無関係なAI生成画像を自動採用する機能ではありません。

## プレビューと書き出し

- 編集結果をブラウザ内でプレビュー
- テロップ、カット、ナレーション、元動画音量を反映
- スマートフォンで扱いやすい動画形式へ書き出し
- iPhoneのシーク操作と保存導線を考慮

対応可否はブラウザのメディアAPIと入力コーデックにも依存します。詳細な障害対応は [サポート手順](../operations/support-playbook.md) を参照してください。

## AI原価が発生する操作

成功した文字起こし、台本生成、AIナレーション生成、再生成は外部AIを利用します。次の操作は端末内または既存結果への変更であり、単独では追加のAI生成を行いません。

- テロップの雰囲気、色、表示有無の変更
- カット方法と元動画音量の変更
- 読み方辞書の登録・削除
- 表紙候補の変更
- プレビューと動画書き出し

読み方や台本を変更したあとに音声を再生成すると、AI操作を1回使用します。

## 提供していない、または公開停止中の機能

- ポップキャラクター音声: 日本語イントネーションの品質調整中で公開停止
- Passkeyの新規アカウント作成: 提供しない方針
- 動画素材の通常経路での永続クラウド保存: 行わない
- InstagramまたはYouTubeへの自動投稿: 現在は投稿用データの作成まで

公開ページの説明に、上記を提供中の機能として記載しません。
