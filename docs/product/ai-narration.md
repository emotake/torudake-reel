# AIナレーション

最終確認日: 2026-08-24

## 目的

無言動画だけに限定せず、元の音声がある動画にもAIナレーションを重ねられる編集モードです。利用者はテロップ、映像カット、元動画音量をそれぞれ選べます。

## 公開中の声

| UI表示 | 内部ID | 狙い |
| --- | --- | --- |
| 自然な男性 | calm | 落ち着いて聞き取りやすい説明 |
| 自然な女性 | bright | 明るく自然な案内 |
| ハイテンショントーク | comedy | テンポ、間、感情を強調した印象的な語り |

partyに対応する「ポップキャラクター」は内部互換性のため定義を残していますが、日本語イントネーションの品質基準を満たしていないため、公開UIと生成APIの両方で停止しています。

## 生成モデル

- 通常: gpt-realtime-2.1-mini
- 音声形式: PCM 24kHzをWAVへ変換
- 緊急切り戻し: NARRATION_SPEECH_MODEをlegacyへ明示変更した場合のみgpt-4o-mini-tts
- 音声プロファイル: NARRATION_VOICE_PROFILE

接続開始前や生成中に失敗しても、別の声や旧モデルへ自動で切り替えません。品質が利用者の選択と異なる状態になるのを避け、同じ条件で再試行できるエラーとして返します。

未設定または不正な音声プロファイルはclassicへ戻ります。本番では評価済みのcharacter-v1を明示設定します。プロファイル定義の正本は lib/narration-voice-profiles.ts です。

## 生成の流れ

1. 動画の長さと利用者の設定を確認する。
2. 台本を作成し、表示テロップ用の文章と読み上げ用の文章を分離する。
3. 固有名詞、数字、記号、助詞を日本語の読み上げ向けに整える。
4. 選択した声の人物像、速度、間、感情の指示を適用する。
5. 音声を生成し、固定速度のまま映像へ配置する。
6. 余白や映像側のカットで尺を調整し、声を不自然に引き伸ばさない。
7. 元動画音量、テロップ、カット設定と合成してプレビューと書き出しへ渡す。

## 読み方の修正

表示する漢字を変えず、読み上げだけを修正できます。

- テロップ: 利用者に見せる文章
- 読み方: AI音声へ渡す日本語表現
- 話し方: 文全体のテンポ、間、強調

読み方辞書の登録や削除だけではAPIを呼びません。「台本・読み方・声を反映」など、音声を生成し直す操作が成功したときにAI操作を1回使用します。

## 尺の扱い

音声を動画尺いっぱいに機械的に伸縮しません。優先順位は次のとおりです。

1. 自然な発話速度を保つ。
2. 台本を短く整える。
3. 文間の余白を調整する。
4. 自動カットが有効な場合だけ、映像を自然な区間へつなぎ直す。
5. 自動カットが無効な場合は、元動画の尺と流れを保つ。

## 原価制御

アカウント区分ごとに、1本の編集で許可するAI生成回数を制限します。

| 区分 | AI操作上限 |
| --- | ---: |
| 無料 | 3回 |
| 月額プラン | 6回 |
| 1動画作成 | 5回 |
| 運営 | 10回 |

上限は無限再生成によるAPI原価の増加を防ぐためのものです。端末内の見た目調整、表紙、プレビュー、書き出しでは消費しません。

## 品質評価

声の追加や変更は、実装前に同じ台本で候補を生成し、次をブラインド評価します。

- 日本語イントネーション
- 語尾と助詞の自然さ
- 聞き取りやすさ
- キャラクター性と印象
- 途中切れ、ノイズ、速度変化

候補作成と費用境界は [キャラクター音声評価](../operations/character-voice-evaluation.md) に記載します。権利者の許可がない実在人物の声の模倣や、特定人物と誤認させる音声は採用しません。

## 開示

AI生成音声を使用する場合は、利用者が生成前にその事実を認識できる表示を行います。出力物と投稿時の表示は、利用するプラットフォーム、提供者の要件、適用法令を確認して運用します。
